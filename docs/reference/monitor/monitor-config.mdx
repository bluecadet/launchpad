Settings for process monitoring, window management, and logging.

## Options

The schema applies input defaults. Nested defaults appear separately from their parent object. See [configuration reference conventions](/reference/cli/config-loading/#configuration-reference-conventions).

### `apps`

<ConfigReference id="monitor-options" property="apps" />

Apps to launch and monitor. Each app takes PM2 settings, window management options, and logging preferences. See [App config](#app-config).

### `deleteExistingBeforeConnect`

<ConfigReference id="monitor-options" property="deleteExistingBeforeConnect" />

Deletes existing PM2 processes before connecting, so startup begins clean. Use it for volatile apps or when node processes might quit unexpectedly.

### `windowsApi`

<ConfigReference id="monitor-options" property="windowsApi" />

Advanced Windows API settings for foreground, minimized, and hidden windows. Window operations run only on Windows; PM2 process management and logging work without them. See [Windows window management](/reference/monitor/#windows-window-management) for platform and installation details.

#### `debounceDelay`

<ConfigReference id="monitor-options" property="windowsApi.debounceDelay" />

Delay in milliseconds before windows are ordered after launch. If your app opens its windows slowly, raise this so they end up above the Launchpad terminal window. Higher values also reduce CPU load when apps relaunch often.

### `shutdownOnExit`

<ConfigReference id="monitor-options" property="shutdownOnExit" />

Listens for exit events and shuts down gracefully.

## App config

Each app in the `apps` array accepts these settings:

### `pm2`

<ConfigReference id="monitor-options" property="apps[].pm2" />

PM2 configuration for the app. See the [PM2 documentation](https://pm2.keymetrics.io/docs/usage/application-declaration/#attributes-available) for the full `StartOptions` API. The table below lists only the fields Launchpad declares; PM2 accepts more.

```typescript
monitor({
  apps: [{ pm2: { script: './app.js', out_file: './app-out.log' } }],
});
```

<ConfigFieldTable id="monitor-options" property="apps[].pm2" caption="Launchpad-declared fields (relative to pm2)" />

### `windows`

<ConfigReference id="monitor-options" property="apps[].windows" />

Window management settings for Windows. All flags default to `false` and apply to the app's visible top-level windows, matched by PM2 process ID.

Window operations run asynchronously after launch, delayed by `windowsApi.debounceDelay`. They don't change PM2 configuration or launch order. On other platforms these settings do nothing.

#### `foreground`

<ConfigReference id="monitor-options" property="apps[].windows.foreground" />

Requests foreground placement after launch. Windows focus restrictions can block it.

#### `minimize`

<ConfigReference id="monitor-options" property="apps[].windows.minimize" />

Minimizes windows after launch.

#### `hide`

<ConfigReference id="monitor-options" property="apps[].windows.hide" />

Hides windows after launch. Hiding can cause problems for GUI-based apps.

### `logging`

<ConfigReference id="monitor-options" property="apps[].logging" />

Log management settings.

#### `logToLaunchpadDir`

<ConfigReference id="monitor-options" property="apps[].logging.logToLaunchpadDir" />

Writes logs to the Launchpad directory.

#### `mode`

<ConfigReference id="monitor-options" property="apps[].logging.mode" />

Log capture method: `'bus'` or `'file'`.

#### `showStdout`

<ConfigReference id="monitor-options" property="apps[].logging.showStdout" />

Includes stdout output.

#### `showStderr`

<ConfigReference id="monitor-options" property="apps[].logging.showStderr" />

Includes stderr output.
